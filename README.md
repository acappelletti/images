# images

Immagini pubbliche usate dai progetti di Alen Cappelletti, servite da `raw.githubusercontent.com` (le email HTML non
possono incorporare immagini: le scaricano da un indirizzo pubblico).

| Cartella | Contenuto |
|---|---|
| [`suite/`](suite/) | Immagini delle email della suite [SQL Server HTML Email Notifications](https://github.com/acappelletti/SQL-Server-HTML-Email-Notifications): una sottocartella per marchio, con il README e le miniature |
| [`suite/flycheck/`](suite/flycheck/) | Marchio predefinito (testata, mascotte, logo del piè di pagina); indirizzo di base `https://raw.githubusercontent.com/acappelletti/images/main/suite/flycheck/` |
| [`suite/custom/`](suite/custom/) | Marchi personalizzati e di prova, uno per cartella (oggi `retiarius/`, banner di testata e piè di pagina) |
| [`suite/graphic/`](suite/graphic/) | Elementi grafici neutri, comuni a tutti i marchi (sfumatura delle intestazioni dei listing `thead.png`); indirizzo `https://raw.githubusercontent.com/acappelletti/images/main/suite/graphic/` |
| [`FlyCheck/`](FlyCheck/) | Prima versione delle immagini e sorgenti SVG del marchio, non più usata dalle email |

Regole: PNG con fondo trasparente al doppio della dimensione mostrata, nomi dei file in minuscolo senza spazi; un nuovo
marchio è una nuova cartella sotto `suite/custom/`, aggiunta al README di `suite/`.
